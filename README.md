# VPN-клиент Роскомнадзора — Прототип СКЗИ

**Статус:** Прототип. Готов к передаче на сертификационные испытания по ПКЗ-2005 (Приказ ФСБ №66).

## Архитектурная схема

```
┌─────────────────────────────────────────────────────────────────┐
│                        main.py (точка входа)                     │
│           Загрузка конфига → Handshake → Запуск туннеля          │
└────────────────┬────────────────────────────────────────────────┘
                 │
     ┌───────────┼──────────────────────────────┐
     │           │                              │
┌────▼──────┐  ┌─▼─────────────┐  ┌────────────▼──────────┐

│ manager   │  │ Аутентификация │  │ TUN + asyncio-циклы    │
│ .py       │  │ X.509 + ECDH   │  │ TUN→Server, Server→TUN │
│ Pull с    │  │ Верификация    │  │ Keepalive, Rekey-монит.│
│ сервера   │  │ цепочки УЦ     │  │                        │
└────┬──────┘  └────┬──────────┘  └───────────┬────────────┘

     │         ┌────▼──────────────────────────▼──────────┐
```

## Формат кадра

```
┌──────────────┬────────────────┬─────────────┬─────────────────┬────────────┐
│ session_id   │ seq_num        │ payload_len │ enc_payload     │ mac        │
│ 4 байта (BE) │ 8 байт (BE)   │ 2 байта(BE) │ N байт          │ 32 байта   │
└──────────────┴────────────────┴─────────────┴─────────────────┴────────────┘
  Итого заголовок: 14 байт. MAC защищает весь кадр кроме себя.
  IV для Кузнечик CTR = seq_num as 8-byte big-endian (уникален для каждого пакета).
```

## Установка и запуск

### 1. Требования к системе

- Astra Linux Special Edition «Смоленск» 1.7 или совместимая Linux-система
- Python 3.10+
- Запуск от root (требуется CAP_NET_ADMIN для TUN)

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Генерация тестовых сертификатов

```bash
python -m utils.cert_gen
```

Создаёт файлы в `certs/`: `ca.der`, `ca_key.bin`, `client.der`, `client_key.bin`, `server.der`, `server_key.bin`.

### 4. Запуск сервера-заглушки

```bash
python server.py
```

Сервер запускается на `0.0.0.0:8443` (VPN) и `0.0.0.0:8444` (управление).

### 5. Запуск клиента

```bash
sudo python main.py config_bootstrap.json
```

### 6. Запуск тестов

```bash
python -m pytest tests/ -v
# или
python -m unittest discover tests/
```

## Криптографические алгоритмы

| Функция | Алгоритм | Стандарт | Реализация |
|---------|----------|----------|-----------|
| Шифрование | «Кузнечик» режим CTR | ГОСТ Р 34.12/34.13-2015 | pygost.gost3412/3413 |
| Хэширование | «Стрибог-256» | ГОСТ Р 34.11-2012 | pygost.gost34112012 |
| Имитозащита | HMAC-Стрибог-256 | RFC 2104 + ГОСТ Р 34.11-2012 | Ручная реализация |
| Подпись | ГОСТ Р 34.10-2012-256 | ГОСТ Р 34.10-2012 | pygost.gost3410 |
| Согласование ключей | VKO ГОСТ Р 34.10-2012 | ГОСТ Р 34.10-2012 | pygost.gost3410 |
| Деривация ключей | KDF = HMAC_Стрибог256(secret, label\|\|0x01\|\|ctx) | RFC 7836 (адаптировано) | pygost_provider.py |
| Кривая EC | id-tc26-gost-3410-2012-256-paramSetA | TC26, RFC 7836 | pygost (встроена) |

## Параметры безопасности

- **Ключ шифрования:** 256 бит (32 байта)
- **Ключ имитозащиты:** 256 бит (32 байта)
- **IV (синхропосылка):** 64 бит, уникальна для каждого пакета (из seq_num)
- **Имитовставка:** 256 бит (32 байта)
- **Порядковый номер:** 64 бит, защита от replay
- **Период смены ключей:** 3600 с или 100 МБ (настраивается)
- **Максимальный срок сессии:** 86400 с (24 часа)

## Готовность к сертификации по ПКЗ-2005

Прототип соответствует следующим требованиям Приказа ФСБ России №66:

1. **Криптографические алгоритмы** — используются исключительно ГОСТ-алгоритмы, сертифицированные ФСБ России.
2. **Изоляция криптоядра** — чёткое разделение криптографического, транспортного и управляющего слоёв.
3. **Управление ключами** — генерация, хранение в ОЗУ, затирание после использования.
4. **Документирование** — весь код прокомментирован на русском языке с трассировкой к требованиям.
5. **Открытость исходного кода** — код полностью доступен для анализа регулятором.
6. **Аудит операций** — все криптографические операции журналируются (без раскрытия ключевого материала).

> **Примечание:** Для продуктивного использования требуется:
> - Замена тестовых сертификатов на сертификаты, выданные аккредитованным УЦ
> - Реализация полной проверки CRL/OCSP в `auth.py:_check_crl_ocsp()`
> - Замена `pygost` на аппаратно-сертифицированный криптоускоритель (КриптоПро CSP) через интерфейс `CryptoProvider`
> - Проверка безопасности системного окружения (Astra Linux SE с включённым МАС)
