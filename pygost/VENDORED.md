# Встроенная (vendored) копия pygost

Эта папка — копия библиотеки **pygost** (реализация криптографии ГОСТ
на Python), включённая прямо в репозиторий, а не устанавливаемая через pip.

## Почему так

- `pygost` **не публикуется на PyPI** — `pip install pygost` не находит
  пакет ни на одной версии Python (проверено: 404 от PyPI API).
- Официальный сайт автора, `pygost.cypherpunks.ru`, на момент встраивания
  не отвечает корректно (отдаёт посторонний контент вместо исходников).
- Поэтому пакет включён в проект напрямую, чтобы установка приложения
  не зависела от доступности внешних серверов.

Содержимое этой папки — точная копия пакета `pygost/` из указанного
коммита, без изменений (включая собственные тесты и `.pyi`-стабы автора).
Код приложения (`vpn_core/`, `utils/`, `gui/`) не модифицирует и не
встраивает в себя файлы этой папки — он лишь импортирует их как обычную
библиотеку (`from pygost.gost3412 import ...`).

## Важно про лицензию

pygost распространяется под **GPLv3** (см. `COPYING`). Это влияет на
условия распространения итогового продукта — при подготовке к
сертификации или коммерческому распространению юридически корректно
будет проверить совместимость лицензий с тем, кто отвечает за этот
аспект.
