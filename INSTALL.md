# Как запустить приложение на компьютере

Пошаговая инструкция для начинающих. Приложение — это VPN-клиент с
российской криптографией ГОСТ и графическим интерфейсом.

Есть два способа запуска:

- **Способ 1 (рекомендуется):** один файл `run.bat` / `run.sh` — делает всё сам.
- **Способ 2:** вручную по командам — если хотите понимать каждый шаг.

---

## Что понадобится

1. **Python 3.10 или новее** — язык, на котором написано приложение.
2. Интернет — чтобы один раз скачать библиотеки `pygost` и `PyQt5`.

Проверить, установлен ли Python, можно командой `python --version`
(Windows) или `python3 --version` (Linux/macOS). Если видите номер версии
вроде `Python 3.11.5` — Python уже есть, шаг установки можно пропустить.

---

## Шаг 0. Установка Python (если ещё не установлен)

### Windows
1. Откройте https://www.python.org/downloads/ и нажмите «Download Python».
2. Запустите скачанный установщик.
3. **ОБЯЗАТЕЛЬНО** поставьте галочку **«Add Python to PATH»** внизу окна.
4. Нажмите «Install Now», дождитесь конца.

### Linux (Ubuntu / Debian / Astra Linux)
```bash
sudo apt update
sudo apt install python3 python3-pip
```

### macOS
```bash
brew install python
```
(или скачайте установщик с python.org)

## Шаг 1. Скачать проект

### Вариант с архивом (проще)
1. Откройте страницу репозитория на GitHub.
2. Переключитесь на ветку **`claude/lucid-lamport-gejwan`**
   (кнопка выбора ветки слева сверху над списком файлов).
3. Нажмите зелёную кнопку **Code → Download ZIP**.
4. Распакуйте архив в удобную папку, например `C:\VPN` или `~/VPN`.

### Вариант с git (если установлен)
```bash
git clone https://github.com/altzolotko/myapp.git
cd myapp
git checkout claude/lucid-lamport-gejwan
```

## Способ 1. Запуск в один клик (рекомендуется)

### Windows
Просто **дважды щёлкните по файлу `run.bat`**.

Откроется чёрное окно — оно само:
установит библиотеки → создаст сертификаты → запустит сервер →
откроет графический интерфейс. Через 10–30 секунд появится окно программы.

> Если Windows покажет «Защита Windows / SmartScreen» — нажмите
> «Подробнее» → «Выполнить в любом случае» (это потому, что файл скачан
> из интернета, а не потому, что он опасен).

### Linux / macOS
Откройте терминал в папке проекта и выполните:
```bash
chmod +x run.sh      # один раз — сделать файл исполняемым
./run.sh
```

Скрипт всё сделает сам и откроет окно программы. Когда вы закроете
интерфейс, тестовый сервер остановится автоматически.

---

## Способ 2. Запуск вручную (по шагам)

Откройте терминал в папке проекта.
На **Windows** используйте `python`, на **Linux/macOS** — `python3`.

### 1. Установить библиотеки
```bash
python -m pip install -r requirements.txt
```
Установятся `pygost` (криптография ГОСТ) и `PyQt5` (интерфейс).

### 2. Создать тестовые сертификаты (один раз)
```bash
python -m utils.cert_gen
```
Появится папка `certs/` с тестовыми ключами и сертификатами.
(Это же можно сделать кнопкой в самом интерфейсе.)

### 3. Запустить тестовый сервер
Сервер нужен, чтобы клиенту было к чему подключаться.
**Откройте отдельное окно терминала** и выполните:
```bash
python server.py
```
Оставьте это окно открытым — сервер должен работать всё время.
Вы увидите строки `VPN-сервер запущен на 0.0.0.0:8443`.

### 4. Запустить графический интерфейс
В **первом** окне терминала выполните:
```bash
python vpn_gui.py
```

## Как пользоваться интерфейсом

1. Слева вверху указаны **адрес сервера** (`127.0.0.1`) и **порт** (`8443`) —
   для локального теста менять не нужно.
2. Убедитесь, что выбран режим **«Демо (без TUN)»** (выбран по умолчанию).
3. Нажмите большую кнопку **«ПОДКЛЮЧИТЬСЯ»**.
4. Индикатор слева станет жёлтым (подключение), затем зелёным (подключено).
5. В журнале внизу побегут строки: рукопожатие ГОСТ, выработка ключей,
   обмен зашифрованными пакетами. Справа будет расти счётчик трафика ↑/↓
   и показываться превью ключей шифрования.
6. Чтобы остановить — нажмите **«ОТКЛЮЧИТЬ»**.

> **Демо-режим** показывает всю криптографию (рукопожатие, шифрование
> «Кузнечик», имитозащиту «Стрибог») по TCP, без настройки реального
> сетевого туннеля — поэтому работает без прав администратора и на любой ОС.
>
> **Полный туннель** (реальная маршрутизация всего трафика через TUN)
> запускается из командной строки от имени root/Администратора:
> `sudo python main.py config_bootstrap.json` (Linux) — на Windows
> дополнительно нужен `wintun.dll`, см. README.md.

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| `run.bat` пишет «Python не найден» хотя Python установлен, или открывается окно Microsoft Store | Это «заглушка» Windows (App Execution Alias) вместо настоящего Python — `where` её находит, но она не работает. Установите Python с python.org (галочка «Add Python to PATH»), затем отключите псевдонимы: **Параметры → Приложения → Псевдонимы выполнения приложений** → выключите `python.exe` и `python3.exe`. |
| `python: command not found` / «не является внутренней командой» | Python не установлен или не добавлен в PATH. Переустановите с галочкой «Add Python to PATH». На Linux/macOS используйте `python3`. |
| `No module named pygost` или `PyQt5` | Не установлены библиотеки. Выполните `python -m pip install -r requirements.txt`. |
| `Сертификаты не найдены` | Запустите `python -m utils.cert_gen` или нажмите кнопку «Создать тестовые сертификаты» в интерфейсе. |
| Индикатор красный, «Нет соединения с сервером» | Не запущен сервер. Откройте отдельное окно и выполните `python server.py`. |
| `Address already in use` (порт занят) | Сервер уже запущен в другом окне, либо порт 8443 занят. Закройте лишнее окно. |
| Окно интерфейса не открывается на Linux | Нужен графический рабочий стол (X11/Wayland). По SSH добавьте `-X`, либо запускайте на машине с экраном. |

## Проверка без интерфейса (по желанию)

Можно убедиться, что криптоядро работает, запустив тесты:
```bash
python -m pytest tests/ -v
```

Или текстовую демонстрацию полного цикла шифрования через Docker
(не требует Python и установки — только Docker):
```bash
docker-compose up
```
